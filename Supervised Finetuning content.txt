Using correction logic—often referred to as Chain-of-Thought (CoT) fine-tuning—transforms the LLM from a simple "lookup" tool into a "reasoning" engine for financial data. In financial spreading, where numbers like "Total Debt" must be derived from multiple line items, the difference in accuracy and auditability is significant

"Prompt" Based Critic Model
------------------------

A Critic provides a second "pair of eyes" to catch those confident lies.
Past Correction can be used to build rules and used in prompt. No Training / Fine tuning is needed.

Correction Example 1: "Analyst corrected extraction because the model picked the 'Consolidated' figure instead of 'Parent Company'."
Critic's New Rule: "Always check if the value belongs to the 'Parent' or 'Consolidated' entity. If the RAG picks 'Consolidated' when 'Parent' is requested, flag as High Risk."
